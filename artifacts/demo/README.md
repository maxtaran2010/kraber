# Материалы демонстрации

## Видео

Ссылка на видео: *будет добавлена*

Весь сценарий показан в авиарежиме, Bluetooth включён только для часов.

1. Импорт аудиофайла, выбор числа спикеров (Авто), прогресс обработки, расшифровка со спикерами и таймкодами.
2. Тап по реплике: проигрывание с подсветкой слов. Вкладки Кратко (конспект локальной LLM) и Вопросы.
3. Экспорт JSON по ТЗ.
4. Часы: запись одним тапом, волна на часах, живой текст на телефоне, Стоп и полная расшифровка.

## Пример: вход и результат

В `example/` лежит тестовый диалог заседание котов (3 голоса, 36 с) и то, что выдало приложение.

| Файл | Что это |
|---|---|
| `dialog1.wav` | входной файл (16 кГц mono) |
| `dialog1.result.json` | результат приложения, JSON строго по ТЗ (`transcript[]`: `speaker_id`, `start_ms`, `end_ms`, `text`) |
| `dialog1.reference.json` | эталонная разметка |

Сверка:

```bash
python3 tools/eval/eval.py example/dialog1.reference.json example/dialog1.result.json
```

Результат: WER 4.84 %, DER 6.22 %, спикеров 3 из 3. Ошибка границ реплик: начало ±62 мс, конец ±146 мс.
