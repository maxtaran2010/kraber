# Артефакты тестирования

`results.csv`: результаты прогона тестового набора через приложение по каждому файлу (WER, DER, ошибка границ, время обработки, RTF). Методика и выводы описаны в `docs/TEST_RESULTS.md`.

Тестовые аудио и эталоны генерируются скриптами `tools/eval/make_piper_dialogs.py` и `tools/eval/make_test_dialog.py` и в Git не хранятся. Прогон: `tools/eval/device_eval.sh <файлы>`.
