## Задача
Android-приложение, которое **локально, без интернета** превращает аудио разговора в текст
с разделением по спикерам и таймкодами. Приватность — главное, что оценивает Hex.Team.

## Стек (план)
- Android, Kotlin, Jetpack Compose
- **sherpa-onnx** — ASR (русские модели: GigaAM / Whisper / Vosk) + speaker diarization
  (pyannote segmentation + speaker embedding)
- Wear OS-модуль для часов (Compose for Wear OS), связь через Wearable Data Layer API
- Локальная LLM для саммари (llama.cpp, маленькая модель ~0.5–1.5B) — опционально
- Сборка/деплой на телефон по USB через adb

## Приоритеты
**P0 — ядро (без него ничего не имеет смысла):**
запись → транскрипция → разделение по спикерам → таймкоды → экран с текстом

**P1 — «срыв башки»:**
1. Живая транскрипция по ходу разговора
2. Локальное саммари: итоги, задачи, кто что обещал
3. Имена вместо «Спикер 1» — enrollment голоса
4. Часы: старт записи одним тапом + анимация волны, последняя фраза бегущей строкой,
   кнопка «отметить важный момент» с вибрацией
5. Привязка часов к телефону по QR-коду, без аккаунтов

**P2 — если останется время:**
- Тап по фразе → проигрывание этого куска аудио, поиск по всем разговорам
- Цветная лента «кто сколько говорил»
- Экспорт в PDF / Telegram
- Облачная синхронизация — **только opt-in и с E2E-шифрованием** (по умолчанию всё локально,
  иначе противоречит сути задачи)

## Как устроено сейчас (v2-пайплайн)
VAD (Silero) → ASR каждого куска речи целиком (GigaAM v3 RNNT, таймкоды токенов → слова; тире «—» в выводе = смена реплики)
→ диаризация (своя, pyannote убран): смена спикера по эмбеддингам CAM++ скользящим окном + тире, AHC-кластеризация кусков → спикер каждому слову → сглаживание → реплики.
LLM (Qwen3 1.7B int4, LiteRT-LM) — в отдельном процессе `:llm`, запускается только когда очередь расшифровок пуста;
пишет название и 2–4 итога (раздела «Задачи» нет — 1.7B их выдумывала), текст реплик не трогает.
Имена спикеров — `ml/SpeakerNamer.kt` (правила: обращения/самопредставления + голосование, лучше «Спикер N», чем чужое имя);
хранятся в meta.json (`speakerNames` авто, `speakerNamesUser` ручные), в JSON-экспорт не идут. Тесты: `./gradlew :app:testDebugUnitTest`.

Оценка качества: `tools/eval/` — `proto_pipeline.py` (Python-зеркало пайплайна, venv в `.cache/venv`),
`bench.sh` / `sweep.sh` (тестовый набор `.cache/test/piper_*.wav` от `make_piper_dialogs.py`),
`device_eval.sh` (прогон через debug-APK на устройстве: `am start ... --ez autostart true`), `eval.py` (WER/DER/границы).
Конспекты: `llm_compare.sh <id>...`. Сборка+установка: `scripts/dev_install.sh` (`VARIANT=release` — release; сам освобождает место на эмуляторе).
Часы: модуль `src/android/wear` (`app.glagol.wear`, applicationId тот же `app.glagol` — иначе Data Layer не свяжет), запись → поток
PCM по `ChannelClient` → телефон `watch/WatchHub.kt` (живой текст + полная расшифровка, ACK; протокол `WatchProtocol.kt` —
копия в обоих модулях). Эмуляторы: AVD `glagolwatch` (Wear OS 5), мост `adb forward tcp:7788` (debug), `scripts/wear_install.sh`.
Документация для сдачи: `README.md`, `docs/ARCHITECTURE.md`, `docs/LIMITATIONS.md`, `docs/TEST_RESULTS.md`, `artifacts/test-results/results.csv`.
